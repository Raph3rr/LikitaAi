LikitaAI Frontend Application

Overview

This is the frontend of the project. It provides the user interface and communicates with the backend service.


Requirements
	•	Node.js
	•	npm


Setup Instructions
	1.	Open a terminal
	2.	Navigate to the frontend folder:
cd frontend
	3.	Install dependencies:
npm install
	4.	Start the development server:
npm run dev


Notes
	•	Ensure the backend server is already running
	•	The application will open in your browser automatically
	•	The development server URL will be displayed in the terminal (e.g., http://localhost:5173)


Troubleshooting
	•	Run npm install if dependencies are missing
	•	Ensure you are in the correct directory before running commands
